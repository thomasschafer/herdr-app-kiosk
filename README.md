# herdr-app-kiosk

Kiosk, the repository and branch picker for the [Herdr](https://herdr.dev) desktop app, has
moved to [thomasschafer/kiosk](https://github.com/thomasschafer/kiosk), and this repository is
archived. Its releases up to v0.4.0 stay here.

The old install commands still work, and install the latest release from the new repository:

```sh
curl -fsSL https://raw.githubusercontent.com/thomasschafer/herdr-app-kiosk/main/scripts/install.sh | sh
```

```powershell
irm https://raw.githubusercontent.com/thomasschafer/herdr-app-kiosk/main/scripts/install.ps1 | iex
```
